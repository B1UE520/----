Q：隐藏文字一直显不出来？

A：需按住鼠标右键（不是左键）在留白区域内缓慢拖动。触屏设备用手指拖动即可，不要点击。

Q：第二页 / 第三页密码输不进去？

A：请确认输入法处于英文或中文状态均可，但前后不要有空格。密码为纯数字或纯汉字。

Q：第三页一直不暗化？

A：暗化计时从页面加载后开始，需停留在该页面约 48 秒。频繁切换标签页不会重置计时，但建议保持前台。

Q：第四页的声音按钮点了没反应？

A：请确认浏览器未静音，且已允许页面播放音频。若浏览器版本过旧，可能不支持 Web Audio API。

Q：能否单页部署？

A：四个页面通过 window.location.href 相互跳转，需保持在同一目录下。如需单页应用改造，需将四页内容合并并用前端路由控制切换。
